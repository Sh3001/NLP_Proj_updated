Summary of Key Experimental Findings

  • Input-Conditional Gating: Dynamic routing achieves higher macro F0.5 (0.99481) than any individual model by routing on script and data-completeness signals without knowing the country label.
  • Cross-Lingual Resilience: The learned transliteration lexicon combined with multilingual cross-encoders (mDeBERTa-v3, BGE) resolves Hindi/Malayalam script variation that breaks standard English baselines.
  • Numeric and Structural Disambiguation: Sibling branch disambiguation relies on numeric token mismatches (house/unit numbers) and dense encoder context rather than pure name string similarity.
  • Blocking Ceiling: Records with unexpanded acronyms and missing addresses represent the primary failure mode, bounded by the R@5 candidate recall.
