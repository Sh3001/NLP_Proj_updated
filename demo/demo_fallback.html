Summary of Key Experimental Findings

  • Input-Conditional Gating: Dynamic routing achieves higher macro F0.5 than any individual model by leveraging script and address-completeness indicators.
  • Cross-Lingual Resilience: The learned transliteration lexicon + IndicBERTv2 resolves Hindi/Malayalam script variation that breaks standard English baselines.
  • Address Feature Importance: Sibling branch disambiguation requires explicit token-level alignment (BiLSTM-CRF), which string-only models lack.
  • Blocking Ceiling: Records with unexpanded acronyms and missing addresses represent the primary failure mode, bounded by the R@5 candidate recall.
